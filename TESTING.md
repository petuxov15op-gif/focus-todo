# Проверка проекта

Проверено 12 ноября 2026 года в браузере, встроенном в приложение ChatGPT. Это ручные проверки через управление интерфейсом, а не отдельный автоматизированный тестовый набор.

После переработки дизайна повторно проверены добавление кнопкой и Enter, выполнение, сохранение текста и отметок после обновления, удаление, возврат удалённого, фильтры, пустой ввод, выполнение клавишей Space и длинный текст на узком экране. Существующие задачи из первой версии доступны в новой без переноса данных.

После подключения MagicPath созданы два интерактивных прототипа. Оба прошли сборку TypeScript/Vite, рендеры просмотрены через MagicPath. В прототипе Brutalism отдельно проверены пустой ввод, добавление, выполнение, сохранение после обновления, удаление и возврат удалённого. Его оформление перенесено в локальный сайт. В локальной версии ещё раз проверены четыре функции из задания и обновление нового визуального счётчика. На ширине 320 px найдено и исправлено выступание жёлтой карточки за край; повторная проверка подтвердила равенство ширины документа и экрана. На 375 px сохранён мобильный рендер. Проверено, что `paper.html` читает тот же список и не требует миграции данных.

## Результаты

| Сценарий | Результат |
| --- | --- |
| Отправка пустого поля | Задача не создаётся, показана подсказка |
| Ввод только пробелов | Задача не создаётся |
| Добавление кнопкой | Задача появляется в списке |
| Добавление по Enter | Задача появляется в списке |
| Пробелы по краям | Удаляются при добавлении |
| Отметка выполнения | Чекбокс, оформление и прогресс обновляются |
| Обновление страницы | Список и отметка выполнения сохраняются |
| Фильтр "В работе" | Показывает незавершённые задачи |
| Фильтр "Готово" | Показывает выполненные задачи |
| Снятие отметки в фильтре "Готово" | Задача уходит из фильтра, появляется пустое состояние |
| Удаление | Задача удаляется из списка |
| Возврат удалённой задачи | Задача восстанавливается |
| Обновление после удаления | Удалённая задача не возвращается |
| Задача длиной 200 символов | Добавляется, текст переносится |
| HTML в тексте задачи | Отображается текстом, HTML-элемент не создаётся |
| Вторая вкладка | Читает список; новая задача появляется без обновления |
| Экраны 320, 375 и 768 px | Адаптивная компоновка, ширина документа равна ширине экрана |
| Экран 1440 px | Десктопная компоновка, горизонтального переполнения нет |
| Синтаксис JavaScript | `node --check app.js` завершается без ошибок |

Проверка не охватывает все браузеры и реальные мобильные устройства. Ветки обработки запрета localStorage и повреждённых данных предусмотрены в коде, но искусственно через браузер не воспроизводились.

## Проверка перед публикацией

13 ноября 2026 года основной и бумажный варианты повторно открыты локально через HTTP. В Playwright проверены добавление кнопкой и Enter, выполнение, сохранение списка и отметки после перезагрузки, фильтры, удаление и возврат задачи. На ширинах 320, 375, 768 и 1440 px горизонтального переполнения нет.

Форма в обоих вариантах недоступна до загрузки JavaScript: при искусственной задержке скрипта раннее нажатие кнопки не меняет адрес страницы. После загрузки поле и кнопка становятся доступны.

## Как повторить основную проверку

1. Запусти сайт по инструкции в README.
2. Добавь две задачи: одну кнопкой, другую по Enter.
3. Отметь одну выполненной и обнови страницу. Проверь текст обеих задач и отметку.
4. Переключи фильтры и проверь состав списков.
5. Удали задачу, нажми "Вернуть", затем удали повторно.
6. Обнови страницу. Удалённой задачи в списке быть не должно.
7. Попробуй добавить пустое поле и пробелы. Должна появиться подсказка без новой задачи.
8. Открой сайт во второй вкладке и добавь задачу в первой. Список во второй должен обновиться.
